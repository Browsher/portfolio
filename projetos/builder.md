# Builder 2.0

**Estágio: em construção, com base funcional.**

Criar páginas de venda envolve organizar seções, ajustar conteúdo, personalizar a aparência e preparar a entrega do site. O Builder reúne essas etapas em uma ferramenta interna de desenvolvimento.

## O que a ferramenta faz

A base implementada permite montar páginas com componentes reutilizáveis, editar conteúdo e cores, configurar efeitos e visualizar o resultado. A exportação prepara um projeto de site separado para a entrega.

*Esquema do fluxo da ferramenta. Esta imagem é uma ilustração do processo, não uma captura da interface.*

## Aplicação comercial

O Builder apoia o serviço de criação e personalização de sites. Ele permite reaproveitar uma base de componentes entre projetos e concentrar o trabalho nas necessidades de cada página.

É uma ferramenta de uso interno. A apresentação demonstra a capacidade de criar soluções para a própria rotina de produção.

## Situação atual

Há uma base funcional de montagem, personalização, prévia e exportação. A conclusão integral e a validação de todos os fluxos ainda estão em desenvolvimento.
